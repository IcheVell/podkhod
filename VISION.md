# Подход — дневник тренировок

**Подход** — небольшое офлайн-приложение для Android, которое помогает фиксировать силовые тренировки в тренажёрном зале.

## Для кого

Для людей, которые регулярно занимаются в зале и хотят записывать выполненные упражнения, рабочие веса и повторения без бумажного блокнота или сложного спортивного сервиса.

## Какую задачу решает

Во время тренировки бывает неудобно вспоминать, с каким весом и сколько повторений удалось сделать в прошлый раз. Приложение позволяет быстро сохранить результаты каждого подхода и позднее посмотреть историю занятий.

## Основная идея

Пользователь открывает приложение, создаёт запись тренировки, добавляет упражнения и указывает вес и количество повторений в каждом подходе. Все записи сохраняются на устройстве и доступны без интернета.

**Главный принцип:** только необходимые функции для ведения тренировочного дневника, без регистрации, подписок и социальных возможностей.
