# Подход

**Подход** — офлайн-дневник силовых тренировок для Android, разрабатываемый на **Kotlin**.

## Планируемый объём работы (MVP)

Приложение позволит пользователю:

1. **Создать тренировку** — указать дату и при необходимости название занятия.
2. **Добавить упражнения** — выбрать упражнение из небольшого встроенного списка или создать собственное.
3. **Записать подходы** — для каждого упражнения ввести вес (кг) и количество повторений; добавить несколько подходов.
4. **Изменить запись** — отредактировать или удалить упражнение, подход либо тренировку.
5. **Просмотреть историю** — увидеть список сохранённых тренировок по датам и открыть любую для просмотра результатов.

## Основные пользовательские сценарии

**Сценарий 1. Запись тренировки**

Пользователь создаёт тренировку, выбирает «Жим лёжа», добавляет подходы «60 кг × 10», «65 кг × 8», сохраняет запись и продолжает тренировку.

**Сценарий 2. Просмотр прошлых результатов**

Перед следующим занятием пользователь открывает историю, выбирает предыдущую тренировку и смотрит, какой вес и сколько повторений выполнял.

**Сценарий 3. Исправление ошибки**

Пользователь замечает неверно введённый вес, открывает сохранённую тренировку и исправляет значение.

## Критерии готовности

Приложение считается готовым, если:

- [ ] Можно создавать и сохранять тренировки с датой.
- [ ] Можно добавлять упражнения из встроенного списка и создавать собственные.
- [ ] Для каждого упражнения можно добавлять подходы с весом и повторениями.
- [ ] Можно редактировать и удалять сохранённые данные.
- [ ] История тренировок отображается по датам; запись можно открыть и просмотреть.
- [ ] После закрытия и повторного запуска приложения данные сохраняются.
- [ ] Основные функции работают полностью без подключения к интернету.
- [ ] Приложение запускается на Android-устройстве или эмуляторе и не завершается с ошибкой при обычном использовании.

## Технологии

- **Язык:** Kotlin.
- **Платформа:** Android.
- **Интерфейс:** Jetpack Compose.
- **Локальное хранение:** Room (SQLite).
